## 4. Rotation

**Not applicable and not requested.** Bucket (a) is empty, so step 4 of the E13a
brief (stop, name the credential, wait for an explicit owner "proceed") never

## 6. Reproducing this

```
git fetch --all --tags --prune
gitleaks detect --source . --log-opts="--all" --redact \
  --report-format json --report-path outputs/e13a/gitleaks-history.json
```
Then the two blob-level sweeps: enumerate with
`git rev-list --objects --all | cut -d' ' -f1 | git cat-file --batch-check | awk '$2=="blob"'`
and `git cat-file blob` each one, grepping for the names in §2 row 2 and for the
live `.env` values in §2 row 3. Do not print matched values.
