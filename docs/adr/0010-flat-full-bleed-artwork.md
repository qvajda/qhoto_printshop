# The generated image is flat full-bleed artwork, never a poster-in-a-room render

The generation prompt forces flat 2D art filling the frame — no frame, border,
wall, room or mockup — and the injected niche is subject and style only, never
scene words like "wall poster".

Recorded as a decision because the first live run **printed lifestyle mockups as
the artwork**: buyers would have received a photograph of a poster on a wall,
printed on paper. The failure was not a bad image, it was a prompt that permitted
a scene, and a reasonable reader looking at the prompt would not guess why the
scene vocabulary is so aggressively excluded.
