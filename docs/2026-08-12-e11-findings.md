## §1. Shipped — GL-68, the missing channel

`compliance_draft.generate_draft_text` now calls `anthropic_client.complete_with_images`
with `candidates.base_image_local_path`. As the PRD predicted, this was a call swap:
`complete_with_images` existed, `_image_content_block` already accepted a local path,
and the column is the one `run_local_and_master_gate` reads five lines away.

Three things went in with it, and two were not in the PRD:

1. `art_brief` is in the prompt (PRD, free).
2. **The brief is sanitised through `sanitize_niche` as well.** Not in the PRD, and it
   matters for exactly the three candidates GL-75 is about: 77/78/79's briefs were
   *written from the unstripped niche*, so passing the raw brief would have re-introduced
   the event wording GL-55 strips out of the niche — through a second door, into the same
   prompt. Test: `test_draft_prompt_sanitises_the_art_brief_too`.
3. **The prompt states which side wins.** "Where the artwork and the niche/brief disagree,
   THE ARTWORK WINS: the buyer receives the artwork, not the brief." Without that line the
   model has two conflicting sources and no rule.

**One deliberate softening, flagged because it is the kind of thing that rots:** if
`base_image_local_path` is set but the file is gone, drafting falls back to the text-only
call and prints a warning rather than failing. Blind drafting is the GL-68 defect itself,
so it is never silent — but a missing master is a storage fault, not a reason to fail a
draft. If the warning ever shows up in a real run, that is a GL-69-class finding of its
own and should be read as one.

## §4. Shipped with a caveat — GL-69, the code half

`etsy_client.upload_listing_image` takes `alt_text` and writes it as a multipart field;
`group_product`'s upload loop reads `product_images.alt_text`, and **refuses to upload an
image whose alt text can never be set** rather than shipping an empty string. The
secondary-group half is covered by `compliance_draft.fallback_alt_text` — derived from the
listing title rather than drafted by a model, because alt text on a mockup *photograph*
only has to say what the photograph shows, and it is written back to the row so a live
read-back is compared against something the DB actually holds.

**⚠️ THE MEASUREMENT THE PRD MADE NON-NEGOTIABLE HAS NOT HAPPENED.** PRD §8 step 3: upload
one image to a throwaway draft and read `alt_text` back, because this project's convention
is *verify by measurement, not by status code* and GL-22a Q2 is the row that earned it.
That is a live Etsy call, so it is not this session's to make. **Do not run the gallery
re-upload until it is done.** Two outcomes to be ready for: the field is accepted (ship as
is), or Etsy ignores/rejects it (the field name or the transport is wrong, and the code
above is the thing to change — nothing else depends on it).

The false docstring in `check_forbidden_terms` is corrected rather than deleted: it now
says the claim was untrue when written, and names what makes it true now. An assertion in
a comment is a preference; the sentence is kept only because it points at the control.
